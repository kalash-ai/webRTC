🎯 Purpose
This project is purely for educational purposes — to understand the core concepts of WebRTC (Web Real-Time Communication) including peer-to-peer connections, signaling, media streams, and data channels.
No production use intended. Just learning by doing. 🚀

📚 What I'm Learning

How WebRTC establishes peer-to-peer connections
The role of Signaling Servers in WebRTC
ICE (Interactive Connectivity Establishment) and how peers find each other
SDP (Session Description Protocol) — offers and answers
Accessing camera/microphone via getUserMedia()
Sending real-time audio/video streams between peers
Using RTCDataChannel for text/data transfer


🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript (Vanilla)
Signaling: Node.js + Socket.io (or update as needed)
Protocol: WebRTC API (built into modern browsers)
